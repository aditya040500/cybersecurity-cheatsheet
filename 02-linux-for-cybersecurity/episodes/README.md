## How to read these notes

Each note separates **video evidence** (public description, chapter markers, or transcript material that could be accessed) from **reference guidance** added to explain and practise the topic. Command examples are written for an isolated Kali Linux VM or a temporary directory under the learner's home directory. Examples are illustrative; no Linux command output is presented as a test result.

The playlist includes demonstrations intended to alter users, packages, services, processes, or files. Read the impact notes before practising. Use only systems you own or have permission to administer. In particular, do not reproduce the destructive demonstration from episode 10 on a host that contains data you need.
