# Glossary

| Term | Definition |
| --- | --- |
| Authentication | Process of verifying an identity. |
| Authorization | Decision about which actions or resources an authenticated identity may use. |
| Availability | Property that systems and information are accessible when needed. |
| CIA triad | Confidentiality, integrity, and availability; three core security objectives. |
| Control | Safeguard or process intended to reduce risk. |
| DNS | Domain Name System; resolves names to records such as IP addresses. |
| Incident | Event that meets an organization's criteria for security response. |
| Integrity | Property that information remains accurate and changes are authorized. |
| Least privilege | Limiting access to the minimum needed for an approved task. |
| Port | Transport-layer number used to distinguish service endpoints on a host. |
| Protocol | Agreed rules for exchanging and interpreting data. |
| Risk | Potential for loss or harm, assessed using likelihood and impact in context. |
| SIEM | Security information and event management system that collects and correlates security events. |
| Threat | Actor, event, or circumstance that could cause harm. |
| Vulnerability | Weakness that can be exploited or otherwise contribute to harm. |
