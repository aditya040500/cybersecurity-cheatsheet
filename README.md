# Cybersecurity Knowledge Base

Personal study notes and quick references for cybersecurity fundamentals and Linux. Each topic has an editable Markdown source; the completed fundamentals and Linux sections also include print-ready PDF handbooks.

These notes support revision and practical reference. They are not a certification record or a substitute for vendor documentation and hands-on practice.

## Scope and source access

The Google course page publishes an eight-course curriculum; its public playlist feed exposes module video titles but not lesson transcripts. The NetworkChuck playlist feed exposes the episode titles, and episode 1's public description includes chapter markers. Detailed transcripts were not available. Notes identify these source limits and avoid claiming that every command or concept came from a specific video.
